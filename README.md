# Paradise Nursery

Paradise Nursery is an interactive, single-page e-commerce web application built with React and Redux. It allows users to browse a variety of beautiful houseplants categorized by type, add them to a shopping cart, and manage their selections.

## Features
- Interactive landing page with company overview
- Dynamic product catalog grouped by categories (Air Purifying, Aromatic, Succulents)
- Redux-managed shopping cart state
- Real-time cart updates (item counts, sub-totals, and total cost)
- Responsive navigation bar
